Forensics Triage Tool: a Python tool (standard library only) I wrote while teaching myself digital forensics for the GCFE. It opens a folder of evidence and a raw disk dump strictly read-only, hashes every file (MD5, SHA-1, SHA-256) against known-bad and known-good lists, builds a MACB-style timeline, flags files in disguise and faked timestamps, carves deleted JPEG, PNG, PDF and ZIP files out of raw data by checking their structure, pulls out IOCs, reads a Chrome-style History database plus Prefetch and registry exports, and keeps a hash-chained custody log with before and after evidence hashes. It writes JSON and Markdown case reports and a static dashboard designed like a paper case file, with folder tabs, an evidence board, a vertical story strip and a custody page that recalculates the hash chain in your browser. The sample case is a clearly labelled synthetic insider-exfiltration story, checked against my own answer key, so it shows the tool does what I meant and not how it would do on real cases. The project has 262 pytest tests.
