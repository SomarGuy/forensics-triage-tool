Digital Forensics Triage Tool: a standard-library Python tool that handles a folder of evidence and a raw disk dump strictly read-only, hashes every file (MD5/SHA-1/SHA-256) against known-bad and known-good lists, builds a MACB-style timeline, flags extension/magic-byte mismatches and timestomping indicators, carves deleted JPEG/PNG/PDF/ZIP files from raw data by validating their structure, extracts IOCs, parses a Chrome-style History database plus Prefetch- and registry-style exports, and keeps a hash-chained chain-of-custody log with before/after evidence hashes. It writes JSON and Markdown case reports and a static dark-theme dashboard (interactive timeline, file and IOC tables, carved-file map, in-browser custody-chain verification). The sample case is a clearly labelled synthetic insider-exfiltration storyline checked against a ground-truth file; the project has 254 pytest tests.
